# The-BCG-churn-Project
"Predicting customer churn for PowerCo using Random Forest and Price Sensitivity Analysis (BCG Job Simulation)."
Project Focus: PowerCo Customer Attrition
This project investigates why customers are leaving PowerCo, a major utility provider. Using Python (Pandas, NumPy),I analyzed price sensitivity and engineered features to predict churn.

Key Results
Model Success: Achieved a 50% recall rate using an optimized Random Forest classifier.
Data Insight: Identified key drivers of customer attrition through advanced feature engineering.
Communication: Delivered an executive summary translating complex data into actionable retention strategies.

Tech Stack
Language: Python 
Libraries: Pandas, NumPy, Scikit-learn, Matplotlib 
Algorithms: Random Forest, Predictive Modeling
